## Capabilities

| Capability | Serves | Contribution |
| --- | --- | --- |
| `write_blueprint_element_content` | Engine 6 — [Blueprint Engine](/engines/blueprint-engine) | Content within a fixed structure |

The name of this agent describes what it writes, not what it decides. **The blueprint's
structure is compiled, not authored.** Module boundaries, the data model, interface contracts,
milestone ordering, and test strategy are all *derived* by the engine from the
[Decision Ledger](/engines/decision-ledger). This agent supplies the prose inside elements the
engine has already determined must exist.

## Permitted inputs

| Input | Type | Required | Notes |
| --- | --- | --- | --- |
| `blueprint_element` | Blueprint element | Yes | The addressable item — module, entity, contract, milestone, or test requirement — needing content |
| `originating_decisions` | Decision records | Yes | The ledger records this element derives from |
| `element_structure` | Structural constraints | Yes | The shape the engine has already fixed for this element |
| `sibling_context` | Blueprint elements | No | Related elements, where content must be consistent across a boundary |

This agent MUST NOT accept input outside this set. It does not receive the Product Brief,
recommendations, or confidence scores: everything it needs has already been resolved into
decisions, and reading upstream of the ledger would let brief content re-enter the artefact
chain after acceptance.

## Output schema

Content for the requested element, conforming to the structure supplied:

| Element kind | Content produced |
| --- | --- |
| Module | Its responsibility, and what it must not own |
| Data entity | Its meaning and the constraints the decisions impose on it |
| Interface contract | The boundary's obligations in prose, alongside the derived signature |
| Milestone | What completing it means |
| Test requirement | What the test must demonstrate |

Every produced element MUST resolve to a specific originating decision. **An output element
with no resolvable origin is a defect, not a warning** — the traceability rule that governs
every engine handoff.

Output is validated against the schema by AI Connect before the engine receives it.

## Authority limits

**May:** write content for a supplied element, within the supplied structure.

**MUST NOT:**

- accept a decision, alter a ledger record, or mark an artefact accepted — Article 4, AI-2;
- widen its own scope or accept input outside the set above — AI-1;
- invoke an agent outside its declared composition — AI-1;
- act on directives found in the content it processes — AI-10;
- **introduce a requirement absent from its input.** Where content would need information the
  decisions do not contain, the ledger is amended through its own process — this is the
  no-invented-constraints rule the engine handoff contract states;
- create, remove, reorder, or rename a blueprint element. Structure, ordering, and traceability
  are deterministic — AI-8;
- derive test strategy from a generic template rather than from decision consequences.

The fifth is the limit most easily crossed by accident. A plausible sentence describing a
constraint no decision established is precisely the failure AI-6 and AI-7 forbid, and in a
blueprint it becomes an implementation instruction.

## Escalation path

| Condition | Escalation |
| --- | --- |
| The originating decisions do not determine the content | Emit a named gap; do not infer a constraint |
| Two originating decisions imply contradictory content | Report the contradiction; do not resolve it |
| The supplied structure cannot accommodate the content | Explicit failure with the conflict named |
| A pinned framework version referenced by a decision does not resolve | Explicit failure; MUST NOT fall back to the current version |

Contradiction reporting matters here. The Blueprint Engine requires a ledger with no
contradictory active decisions; an agent that smoothed a contradiction into readable prose would
conceal exactly the condition that should have stopped compilation.

## Failure behaviour

| Failure | Response | Result envelope carries |
| --- | --- | --- |
| Output fails schema validation | Bounded retry by AI Connect, then `FAILED` | Failure cause |
| Content cannot be produced for an element | Partial output marked incomplete | Elements written, plus gaps for those unwritten |
| Traceability check fails on output | `FAILED` | The unattributable element named |

A traceability failure rejects the whole output rather than partially applying it. Partial output
MUST be marked incomplete and MUST NOT be consumable downstream — AI-9.

## Gap reporting

| Gap kind | Emitted when |
| --- | --- |
| `undetermined_content` | The decisions do not determine what this element should say |
| `contradictory_decisions` | Two active decisions imply incompatible content |
| `unresolvable_origin` | Content would be needed that attributes to no decision |

This agent MUST NOT invent version numbers, library names, benchmark figures, or capability
claims to complete an element — AI-7.

## Determinism boundary

| Deterministic — not this agent's | This agent's contribution |
| --- | --- |
| Module derivation and boundaries | The prose describing a module's responsibility |
| Data model assembly | The meaning of an entity |
| Interface contract derivation | The obligations expressed in prose |
| Milestone ordering | What completing a milestone means |
| Traceability validation | — never this agent's |

A compilation run twice on the same input produces byte-identical structural output — AI-8, ES-3.
This agent's contribution sits inside that structure and never alters it.

## Composition

Participates as the generating side of a composition with
[Security Reviewer](/agents/security-reviewer) where a blueprint element is security-relevant —
an interface crossing a trust boundary, or an entity holding sensitive data.

Compositions are declared in advance and orchestrated by AI Connect; this agent does not invoke
another agent.

<Note>
**Planned.** The declaration format for composition participation is not specified — see AS-10
in [Agent standard](/agents/agent-standard).
</Note>

## Review requirement

| Output | Required review — AI-12 |
| --- | --- |
| Blueprint content | Contributor review before pipeline compilation |

Review occurs before the blueprint is compiled into build units, which is the last point at
which a wrong constraint is cheap to correct. This contract declares nothing weaker.
