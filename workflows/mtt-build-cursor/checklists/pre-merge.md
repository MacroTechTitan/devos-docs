# Pre-merge

- [ ] Spec goals met; non-goals untouched
- [ ] Gates green with actual output: tests, typecheck, lint, build
- [ ] Migrations reviewed, applied only with approval, verified by query
- [ ] No secrets or `.env` contents in the diff
- [ ] No hardcoded admin or hidden paths
- [ ] User-visible changes backed by evidence (screenshots, API responses, row counts)
- [ ] Rollback is "revert the merge commit" and that works
